# NoStress App

Aplicativo de gerenciamento de estresse baseado em evidências científicas.

## 📱 Visão Geral

O NoStress App é uma solução mobile criada para ajudar pessoas a gerenciar o estresse e a ansiedade usando métodos comprovados cientificamente. O aplicativo oferece uma variedade de ferramentas interativas que auxiliam na redução dos níveis de estresse, melhorando o bem-estar e a saúde mental.

## ⚠️ Status do Projeto

**Em Desenvolvimento** - Este projeto está atualmente em fase de desenvolvimento ativo e pode passar por mudanças significativas.

## ✨ Funcionalidades

### Gerenciamento de Estresse
- **Exercícios Respiratórios**: Técnica 4-7-8 com animações guiadas
- **Rastreamento de Humor**: Acompanhamento diário com visualização de tendências
- **Níveis de Estresse**: Monitoramento e análise dos níveis de estresse ao longo do tempo

### Avaliação
- **Questionário GAD-7**: Ferramenta de triagem para ansiedade generalizada
- **Resultados de Avaliação**: Visualização e histórico de avaliações anteriores
- **Recomendações Personalizadas**: Baseadas nos resultados das avaliações

### Terapia de Áudio
- **Meditação Guiada**: Sessões de meditação mindfulness
- **Sons Relaxantes**: Biblioteca de sons da natureza e músicas calmantes
- **Recomendações de Áudio**: Sugestões personalizadas com base no perfil do usuário

### Segurança e Privacidade
- **Autenticação Segura**: Sistema de login e registro de usuários
- **Proteção de Dados**: Armazenamento seguro das informações pessoais
- **Acesso de Emergência**: Contatos e recursos de apoio em caso de crise

## 🛠️ Tecnologias

### Frontend
- **Flutter**: Framework para desenvolvimento cross-platform
- **Dart**: Linguagem de programação
- **Provider**: Gerenciamento de estado da aplicação
- **Google Fonts**: Tipografia personalizada
- **Flutter SVG**: Renderização de gráficos vetoriais
- **Lottie**: Animações interativas

### Backend e Armazenamento
- **Firebase Auth**: Autenticação de usuários
- **Cloud Firestore**: Banco de dados NoSQL
- **Firebase Storage**: Armazenamento de arquivos
- **Firebase Analytics**: Análise de uso e comportamento
- **Firebase Messaging**: Notificações push

### Processamento e IA
- **Google ML Kit**: Reconhecimento de expressões faciais
- **TFlite Flutter**: Execução de modelos de Machine Learning
- **Camera**: Captura e processamento de imagens

### Áudio
- **just_audio**: Reprodução de áudio de alta qualidade
- **audio_session**: Gerenciamento de sessões de áudio

### Visualização de Dados
- **fl_chart**: Gráficos interativos
- **Syncfusion Flutter Charts**: Componentes avançados de visualização de dados

### Utilidades
- **intl**: Internacionalização e localização
- **shared_preferences**: Armazenamento local de configurações
- **url_launcher**: Abertura de links externos
- **path_provider**: Gerenciamento de arquivos locais
- **permission_handler**: Gestão de permissões do dispositivo
- **geolocator**: Serviços de localização
- **http**: Requisições de rede
- **uuid**: Geração de identificadores únicos

## 🚀 Configuração

Para configurar e executar o projeto em sua máquina local:

```bash
# Clone o repositório
git clone git@github.com:IvanTenorioDev/NoStress_App.git

# Entre no diretório do projeto
cd NoStress_App

# Instale as dependências
flutter pub get

# Execute o aplicativo
flutter run
```

### Requisitos
- Flutter 3.x ou superior
- Dart 3.x ou superior
- Android Studio / VS Code
- Emulador ou dispositivo físico
